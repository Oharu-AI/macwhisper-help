VERSION UPDATE ── OCTOBER 2026

15.4までに追加・改善されたこと

2026年10月7日（日本時間）公開の15.4では、Qwen3-ASRの対応拡大、録音中の容量不足対策、SpaceXAIのクラウド文字起こし、会議録音の権限・音質改善が行われました。15系で加わった大きな変更もまとめて確認します。

重要：15系はmacOS 15以降が必要

MacWhisper 15.0以降はmacOS 15以上に対応します。macOS 14を使う場合は14.8.1が最終版です。更新前に「 → このMacについて」でmacOSの番号を確認してください。

フォルダで整理

文字起こしをフォルダ・サブフォルダに分け、ドラッグ操作で整理できます。

会議をその場で文字化

録音と同時に話者識別付きのライブ文字起こしを表示します。

Qwen3-ASR

30言語に対応する高精度ローカルモデル。15.4で対応するM1 Macにも拡大しました。

録音を安全に停止

空き容量が少なくなると警告し、ディスクが満杯になる前に録音を安全に止めます。

⚠️ ライブ会議文字起こしはベータ版：公式は、重要な会議では録音が失われる可能性もあると案内しています。重要な場面では別の録音手段も併用してください。

CHAPTER 01 ── HOME

🆕 15系のサイドバー：Queue、History、Transcriptions、Meetings、Dictations、Recently Deletedに加え、文字起こしを整理する「Folders」と話者を管理する「People」が表示されます。下の画像は旧版の配置です。
01 — ホーム画面（サイドバーあり）

起動直後のメイン画面

項目名種別説明

CHAPTER 04 ── MODELS

AIモデル選択

文字起こしに使うAIエンジン（モデル）を選択します。用途に合わせて使い分けることで精度が上がります。

13 — 言語特化モデル選択

Language-Specific（言語特化）モデル一覧

項目名種別説明
Language-Specific（言語特化）カテゴリ カテゴリ 特定の言語に最適化されたモデルのグループ。日本語専用モデルなどが含まれます。
Whisper C++ Japanese（日本語専用モデル） モデル 日本語に特化したWhisperモデル。日本語のみを話す講義などで比較候補になります。15.4実機では話者認識対応の表示がないため、複数話者を分けたい場合はQwen3-ASRまたはLarge v3 Turboを選びます。サイズ：1.52GB。
日本語（Apple Speech） モデル AppleのオンデバイスSpeech認識を使う日本語モデル。ダウンロード不要で使えますが、Whisperより精度は低め。
🎯 日本語の会議・講義録音には：1人の講義なら日本語特化モデルも比較候補です。複数話者を分ける会議は、話者認識対応の「Qwen3-ASR 1.7B」または「Large v3 Turbo」を選びます。
14 — 多言語モデル選択

Multi-Language（多言語）モデル一覧

項目名種別説明
Large v3 Turbo ✓（現在選択中） モデル WhisperKitエンジンの高精度モデル。日本語を含む多言語対応。現在このMacに設定されているデフォルトモデルです（チェックマーク表示）。速度と精度のバランスが良い。
Parakeet v3（494MB） モデル NVIDIAが開発した英語特化モデル。英語のみを扱う場合は高速・高精度。容量494MBとコンパクト。
📌 モデル選択の目安：
日本語・1人の講義 → Japanese（言語特化）も比較
日本語・複数話者 → Qwen3-ASR 1.7B または Large v3 Turbo
日英混在 → Large v3 Turbo
英語のみ → Parakeet v3

Automation（自動化） セクション 文字起こし完了後に自動でアクションを実行する設定です。
Automatically send after finished transcription ON（文字起こし完了後に自動送信） トグル ON ONになっています。文字起こしが終わったら自動で後述のWebhookに送信します。
Title Format（タイトル形式） テキスト Webhookで送信するデータのタイトル形式を指定します。
Zapier webhook 入力欄 ZapierのWebhook URLを入力します。Zapierで自動化フローを作ると「文字起こし完了→Slackに通知」「→Googleスプレッドシートに保存」などが実現できます。
Make.com webhook + API Key 入力欄 Make.com（旧Integromat）との連携設定。Make.comのシナリオURLとAPIキーを入力します。
n8n webhook 入力欄 オープンソースの自動化ツール「n8n」のWebhook URLを入力します。
Custom Webhook（カスタムWebhook） 入力欄 任意のWebhook URLを入力します。自社システムへの連携などに使います。
Obsidian（見切れ） 連携 ノートアプリ「Obsidian」との連携設定。文字起こし結果をObsidianのVaultに自動保存できます。
💡 テレビ販売への活用例：商品説明の文字起こし→Zapier経由でNotionの商品データベースに自動保存、という自動化フローを組むことができます。
S14 — 設定：AI Services

AIサービス設定画面（画像は旧版）

15.2.1以降は、保存したAIサービスに「Test Connection」が表示され、APIキーや接続先が正しく応答するか確認できます。

項目名種別説明
Add another service（別のサービスを追加） ボタン AIチャット・要約に使う外部サービスを追加できます。
Test Connection（接続テスト） ボタン 登録したAIサービスが正しく設定され、応答できる状態かを確認します。失敗した場合はAPIキー、利用枠、モデル名を見直してください。
Google（Gemini） 選択肢 Google GeminiのAPIを使います。APIキーが必要。
LM Studio 選択肢 ローカルで動くLLMツール「LM Studio」と連携します。オフラインで高精度なAIが使えます。
Ollama 選択肢 ローカルLLMツール「Ollama」と連携します。LlamaやMistralなどのモデルが使えます。
OpenAI（ChatGPT） 選択肢 OpenAI APIの対応モデルを使います。APIキーが必要で、ChatGPTの契約とは料金体系が別です。
OpenRouter 選択肢 複数のAIモデルをまとめて使えるサービス「OpenRouter」と連携します。
Anthropic（Claude） 選択肢 ClaudeのAPIを使います。高精度な要約・分析が可能です。
Azure（Microsoft Azure OpenAI） 選択肢 Microsoft Azure経由のOpenAI APIを使います。
SpaceXAI（旧xAI） 選択肢 GrokモデルのAPIを使います。15.3からサービス名の表示がSpaceXAIへ更新されました。
Hugging Face 選択肢 Hugging FaceのホスティングAPIを使います。
Deepseek 選択肢 中国発の高性能AI「Deepseek」のAPIを使います。
Groq 選択肢 Groq（超高速AI推論）のAPIを使います。無料枠が大きく試しやすいです。
Custom（カスタム） 選択肢 任意のOpenAI互換APIエンドポイントを設定できます。
Foundation Model（基盤モデル）→ Apple 現在の設定 デフォルトはAppleのオンデバイスAI（Apple Intelligence）を使用します。無料・オフラインで動作します。
保存済みAIサービス 設定済み 登録したサービスとモデルが表示されます。利用可能なモデル名は各社の更新で変わるため、Test Connectionで動作を確認してください。
💰 API課金をしない使い方：MacWhisper内でGemini・ChatGPT・Claudeへ直接接続はせず、文字起こしはLocal Modelsで完了させます。その後、完成した文章を契約中の各AIアプリへ手動で貼り付ければ、要約・議事録化・文章整理には活用できます。MacWhisper内だけで処理したい場合はApple Foundation Models、LM Studio、Ollamaなどのローカル手段を使います。
